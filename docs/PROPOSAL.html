Executive Summary

Jareeda is a production-ready multilingual news platform built with Laravel 13, featuring a classic newspaper-style layout with justified text in both English and Arabic. The platform aggregates 230+ Bahrain news articles from NewsAPI.ai and RSS feeds, with full content and featured images.

Features

  • Newspaper-style multi-column CSS layout with justified text
  • Full RTL support for Arabic content
  • NewsAPI.ai integration with 12-hour caching to preserve API tokens
  • RSS feed aggregation from Biz Bahrain, Bahrain This Week, Google News
  • Playwright-powered full article content scraping
  • Automated image downloading from og:image and article pages
  • AI image generation fallback via Unsloth FLUX2
  • 30 articles displayed on homepage with featured article highlight
  • Source attribution and publication dates for every article
  • Responsive design for mobile and desktop

API Token Management

NewsAPI.ai provides 2,000 free tokens/month. The platform implements a 12-hour cache that reduces API calls by approximately 95%. Each fetch cycle uses ~120,000 tokens but runs only twice daily via cache, resulting in approximately 240,000 tokens/day usage — well within limits when combined with RSS feeds.
