📰 Jareeda

Arabic/English Newspaper Platform — Development Proposal

August 15, 2026

1. Executive Summary

Jareeda is a bilingual (Arabic/English) newspaper-style web platform built on Laravel 13 with TypiCMS. It aggregates Bahrain news from multiple RSS feeds and NewsAPI.ai, displays articles in a classic newspaper multi-column layout with justified text, and generates AI images for articles missing them.

3. UX Implementation

3.1 Newspaper Layout NEW

The homepage displays articles in a classic newspaper multi-column layout with:

  • Multi-column grid — 3 columns on desktop, 2 on tablet, 1 on mobile
  • Justified text — authentic newspaper feel with hyphenation
  • Featured article — full-width hero with large image
  • Column rules — subtle vertical dividers between columns
  • Category badges — color-coded article categories

3.2 Arabic/RTL Support FIXED

Three critical UX issues were identified and fixed:

  1. Google Fonts loaded — Playfair Display, Source Serif 4, Inter for English; Noto Naskh Arabic, Amiri for Arabic
  2. RTL direction set — dir="rtl" applied to <html> for Arabic pages
  3. Container placement — newspaper section moved inside .container-xl

4. Image Generation Pipeline

4.1 Pipeline Architecture

  1. RSS Download — Extract images from RSS feed media tags
  2. Page Scraping — Follow article URLs, find og:image or first image
  3. AI Generation — Generate with Unsloth FLUX2 or DiffusionBee FLUX.1 as fallback

5.2 Commands

# Fetch news from NewsAPI.ai (cached 12 hours)
php artisan news:fetch-newsapi --days=7 --limit=100

# Fetch from RSS feeds
php artisan news:fetch-bahrain --days=7 --limit=50

# Scrape full content with Playwright
php artisan news:scrape-content --limit=50

# Process images (download → scrape → generate)
php artisan news:process-images --limit=100

# Ensure all articles have images
php artisan news:ensure-images

# Take E2E screenshots
npx tsx scripts/take-screenshots.ts
